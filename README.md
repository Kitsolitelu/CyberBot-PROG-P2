# CyberBot — Cybersecurity Awareness Chatbot (Part 2)

## Project Description
A WPF-based Cybersecurity Awareness Chatbot built in C#. 
The bot helps users learn about cybersecurity topics including 
password safety, phishing, malware, scams, privacy and safe browsing.

## Features
- GUI built using WPF (Windows Presentation Foundation)
- Keyword recognition for cybersecurity topics
- Random responses using Lists and Dictionary collections
- Memory and Recall :remembers user name and favourite topic
- Sentiment Detection : adjusts responses based on user mood
- Conversation flow : supports follow-up questions
- Error handling for unrecognised inputs
- Voice greeting on startup
- ASCII art header from Part 1

## Files
| File / Purpose 
| ChatBot.cs , Core logic — keywords, memory, sentiment, random responses |
| MainWindow.xaml , WPF layout — GUI design |
| MainWindow.xaml.cs , Code-behind — connects GUI to ChatBot logic |
| TopicWindow.xaml , Topic detail page layout |
| TopicWindow.xaml.cs ,Topic detail page logic |
| voice_audio.wav , Voice greeting audio file |

## How to Run
1. Open the solution in Visual Studio
2. Set target framework to .NET 8.0 Windows
3. Press F5 to run
